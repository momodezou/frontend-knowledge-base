# CSS 盒模型

> 重点掌握盒模型组成、尺寸计算、`box-sizing` 和 margin 合并。这些知识直接影响布局尺寸，也是 CSS 面试高频考点。

## 一、盒模型由什么组成 ⭐⭐⭐

每个 CSS 盒子由内向外包括：

1. **Content（内容区）**：文本、图片等实际内容。
2. **Padding（内边距）**：内容与边框之间的空间。
3. **Border（边框）**：围绕 padding 和 content。
4. **Margin（外边距）**：盒子外侧与其他盒子之间的距离。

```css
.box {
  width: 200px;
  padding: 20px;
  border: 5px solid #333;
  margin: 10px;
}
```

## 二、标准盒模型与 IE 盒模型 ⭐⭐⭐

### 1. 标准盒模型：`content-box`

`width` 和 `height` 只指定内容区尺寸。

上例的实际内容盒宽度为：

`200 + 20 × 2 + 5 × 2 = 250px`

若计算占据的水平空间，还要考虑左右 margin：

`250 + 10 × 2 = 270px`

### 2. IE 盒模型：`border-box`

`width` 和 `height` 包含 content、padding、border，不包含 margin。

```css
.box {
  box-sizing: border-box;
  width: 200px;
  padding: 20px;
  border: 5px solid #333;
}
```

此时内容区宽度为：

`200 - 20 × 2 - 5 × 2 = 150px`

**高频结论：**

| 属性 | `content-box` | `border-box` |
|---|---|---|
| width 包含 content | 是 | 是 |
| width 包含 padding | 否 | 是 |
| width 包含 border | 否 | 是 |
| width 包含 margin | 否 | 否 |

项目中常见的全局设置：

```css
*,
*::before,
*::after {
  box-sizing: border-box;
}
```

这样更容易按设计稿控制组件外部尺寸。

## 三、`box-sizing` 的易错点 ⭐⭐

- `border-box` 不会把 margin 包含进 width。
- 设置 `width: 100%` 后再添加 padding，若仍为 `content-box`，元素可能超出父容器。
- `box-sizing` 不会自动继承；若希望伪元素也统一，通常会显式选择 `*::before` 和 `*::after`。
- `min-width`、`max-width` 等约束也受盒模型计算规则影响。

## 四、Margin 合并（外边距折叠） ⭐⭐⭐

在普通块级流布局中，某些相邻垂直 margin 会发生折叠，最终间距不是简单相加。

### 1. 相邻兄弟元素

两个普通块级兄弟的垂直 margin 相遇时：

- 两个正 margin：取较大值。
- 两个负 margin：取绝对值较大的负值。
- 一个正、一个负：两者相加。

```css
.a { margin-bottom: 30px; }
.b { margin-top: 20px; }
/* 两者之间通常是 30px，而不是 50px */
```

### 2. 父子元素之间

在符合条件的普通块布局中，父元素与第一个/最后一个子元素的垂直 margin 也可能折叠到父元素外侧。

### 3. 如何避免不希望发生的折叠？

可根据布局语义创建新的格式化上下文或增加边界：

```css
.parent {
  display: flow-root;
}
```

也可以使用 border、padding 等方式隔开 margin。不要为了阻止折叠而随意添加视觉上不需要的属性。

**易错点：**

- margin 折叠主要讨论普通块级流中的垂直 margin，不是所有布局模式都会发生。
- Flex、Grid 布局中的项目 margin 不按普通块格式化上下文的方式折叠。
- 浮动元素、绝对定位元素等不参与普通流中相同的折叠规则。

## 五、宽高、百分比与实际占位 ⭐⭐

```css
.parent {
  width: 600px;
  padding: 20px;
}

.child {
  width: 50%;
}
```

`width: 50%` 的参照通常是包含块的内容区宽度；百分比高度则更容易受包含块高度是否确定影响。

布局时要区分：

- CSS 声明的 `width`。
- 盒子的 border-box 尺寸。
- 元素在布局中占据的空间（可能还要考虑 margin）。
- `getBoundingClientRect()` 返回的视口相对几何尺寸（通常包含 padding 和 border，不包含 margin）。
