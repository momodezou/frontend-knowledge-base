# CSS 定位与层叠上下文

> 本文重点区分定位方式、包含块（containing block）与层叠上下文（stacking context）。`z-index` 不生效的问题，通常要从这三个概念一起排查。

## 一、position 五种常见取值 ⭐⭐⭐

| 值 | 是否脱离普通文档流 | 定位参照与特点 |
|---|---|---|
| `static` | 否 | 默认值，`top/right/bottom/left` 不用于定位 |
| `relative` | 否 | 保留原本空间，视觉位置相对自身原位置偏移 |
| `absolute` | 是 | 相对最近的定位包含块定位 |
| `fixed` | 是 | 通常相对视口定位；特定祖先可建立其包含块 |
| `sticky` | 否（仍参与流布局） | 在滚动容器内达到阈值后表现为粘性定位 |

### relative

```css
.item {
  position: relative;
  top: 10px;
  left: 20px;
}
```

元素仍占据原本布局空间，只是视觉位置偏移。常用于给绝对定位子元素建立定位参照。

### absolute

```css
.parent {
  position: relative;
}

.child {
  position: absolute;
  top: 0;
  right: 0;
}
```

绝对定位元素脱离普通流，通常寻找最近的、能够建立绝对定位包含块的祖先，而不是必然相对直接父元素。

### fixed

通常相对视口固定；但祖先元素的 `transform`、`filter`、`perspective` 等属性在符合规范条件时可以为 fixed 后代建立包含块，因此它不总是相对浏览器视口。

### sticky

```css
.header {
  position: sticky;
  top: 0;
  z-index: 10;
}
```

常见限制：

- 至少指定一个对应滚动轴的阈值，例如 `top: 0`。
- 粘性定位受最近滚动容器和包含块尺寸约束。
- 祖先的 `overflow` 设置可能改变其滚动容器，导致 sticky 看起来不生效。
- 它不会像 fixed 一样完全脱离普通流。

## 二、绝对定位的包含块 ⭐⭐⭐

常见情况：绝对定位元素通常相对最近的、建立绝对定位包含块的祖先定位。`position: relative/absolute/fixed/sticky` 等定位祖先通常会建立相应包含块；某些非定位属性（如 `transform`）也能建立包含块。

```css
.card {
  position: relative;
  height: 200px;
}

.close {
  position: absolute;
  top: 8px;
  right: 8px;
}
```

**易错点：** `position: relative` 不会让元素脱离文档流；`position: absolute` 才会脱离普通流。绝对定位元素的宽高和 `top/right/bottom/left` 组合也会影响尺寸计算。

## 三、层叠上下文是什么 ⭐⭐⭐

层叠上下文（Stacking Context）可以理解为一个独立的绘制层级环境。内部元素先在自己的上下文中确定绘制顺序，整个上下文再作为一个整体参与外部层叠。

常见创建条件包括：

- 根元素（`html`）。
- 定位元素设置非 `auto` 的 `z-index`（具体条件依布局类型而异）。
- `position: fixed` 或 `sticky`。
- `opacity` 小于 `1`。
- `transform` 不为 `none`。
- `filter`、`perspective` 等特定属性不为 `none`。
- `isolation: isolate`。
- 某些 `contain`、混合模式、will-change 等情况。

```css
.parent {
  position: relative;
  z-index: 1;
  transform: translateZ(0);
}
```

上述属性会创建层叠上下文的情形要按具体属性规范判断；不要把任意 CSS 属性都当成创建条件。

## 四、为什么 z-index 看起来失效？ ⭐⭐⭐

```html
<div class="parent-a">
  <div class="child-a">A</div>
</div>
<div class="parent-b">
  <div class="child-b">B</div>
</div>
```

```css
.parent-a {
  position: relative;
  z-index: 1;
}

.child-a {
  position: relative;
  z-index: 9999;
}

.parent-b {
  position: relative;
  z-index: 2;
}

.child-b {
  position: relative;
  z-index: 1;
}
```

即使 `child-a` 的 z-index 是 9999，它仍被限制在 `parent-a` 的层叠上下文中。`parent-b` 的上下文整体层级更高，因此 B 仍可能覆盖 A。

**排查步骤：**

1. 检查元素是否参与定位或是否适用 z-index。
2. 从目标元素向上检查祖先是否创建了层叠上下文。
3. 找到真正参与同一层级比较的上下文。
4. 调整上下文层级或 DOM/组件结构，而不是无止境增大子元素 z-index。

## 五、常见定位布局

### 居中定位

```css
.parent {
  position: relative;
}

.child {
  position: absolute;
  left: 50%;
  top: 50%;
  transform: translate(-50%, -50%);
}
```

### 固定悬浮按钮

```css
.help {
  position: fixed;
  right: 24px;
  bottom: 24px;
}
```

### 粘性表头

```css
.table-wrap {
  max-height: 400px;
  overflow: auto;
}

thead th {
  position: sticky;
  top: 0;
  background: white;
}
```
