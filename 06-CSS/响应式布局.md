# CSS 响应式布局与适配

> 响应式布局不是简单地把 PC 宽度缩小，而是根据视口、容器、输入方式和内容空间调整布局。重点掌握移动优先、媒体查询、流式尺寸、图片适配和 DPR。

## 一、响应式布局的基本思路 ⭐⭐⭐

常见策略：

1. **流式布局**：使用百分比、Flex、Grid 等，让尺寸随可用空间变化。
2. **断点布局**：在内容不适合当前排列时，通过媒体查询调整结构。
3. **弹性尺寸**：使用 `min()`、`max()`、`clamp()` 限制尺寸范围。
4. **响应式资源**：根据设备和布局选择合适图片。
5. **容器查询**：组件根据自身容器尺寸变化，而不只依赖视口。

移动优先（Mobile First）通常先编写小屏基础样式，再通过 `min-width` 扩展到更宽的屏幕。

```css
.page {
  padding: 16px;
}

@media (min-width: 768px) {
  .page {
    padding: 24px;
  }
}

@media (min-width: 1200px) {
  .page {
    max-width: 1200px;
    margin-inline: auto;
  }
}
```

断点应由内容布局决定，而不是盲目照搬某个设备型号。

## 二、媒体查询 Media Query ⭐⭐⭐

```css
/* 视口宽度至少 768px */
@media (min-width: 768px) {
  .layout {
    display: grid;
    grid-template-columns: 240px minmax(0, 1fr);
  }
}

/* 横屏且较宽的视口 */
@media (orientation: landscape) and (min-width: 700px) {
  .toolbar {
    flex-direction: row;
  }
}
```

常用条件：

- `min-width` / `max-width`：视口宽度。
- `orientation`：横屏或竖屏。
- `prefers-color-scheme`：用户偏好的明暗主题。
- `prefers-reduced-motion`：用户对减少动态效果的偏好。
- `hover`、`pointer`：设备指针和悬停能力。

**易错点：** 媒体查询默认针对视口媒体特征，不等同于某个组件自身的宽度。

## 三、视口与移动端适配 ⭐⭐⭐

移动端页面通常需要正确设置 viewport：

```html
<meta name="viewport" content="width=device-width, initial-scale=1">
```

它让布局视口宽度与设备宽度相匹配，避免移动浏览器使用较宽的虚拟布局视口导致页面缩小显示。

### 视口单位

- `vw` / `vh`：相对视口宽度 / 高度。
- `svh`：小视口高度，适合浏览器 UI 展开时较保守的可视高度。
- `lvh`：大视口高度。
- `dvh`：动态视口高度，会随浏览器 UI 变化。

```css
.hero {
  min-height: 100vh;  /* 旧浏览器回退 */
  min-height: 100dvh;
}
```

**易错点：** 移动浏览器地址栏出现或收起时，`100vh` 的实际表现可能与预期不同。需要根据页面是否允许滚动、是否要避开浏览器 UI，选择合适的视口单位。

## 四、rem、em 与流体排版

```css
html {
  font-size: 16px;
}

.container {
  padding: 1rem;
}

.title {
  font-size: clamp(1.5rem, 3vw, 2.5rem);
}
```

- `rem` 适合基于根字号统一缩放的尺寸。
- `em` 适合相对当前字体尺寸组织组件内部比例，但嵌套时需要注意累乘。
- `clamp()` 适合设置随视口变化但有上下限的尺寸。

不必为了响应式而把所有尺寸都换成 rem；边框、阴影、细小间距等仍可按设计系统使用 px。

## 五、响应式图片与 DPR ⭐⭐

```html
<img
  src="banner-800.jpg"
  srcset="banner-800.jpg 800w, banner-1600.jpg 1600w"
  sizes="(max-width: 700px) 100vw, 800px"
  alt="产品横幅"
>
```

- `srcset`：提供不同尺寸或密度的候选资源。
- `sizes`：告诉浏览器图片在不同条件下预计占据的布局宽度，帮助选择资源。
- `picture`：可按媒体条件或图片格式提供不同资源。
- `object-fit: cover`：在保持比例的前提下填满盒子，可能裁剪内容。

DPR（设备像素比）表示设备像素与 CSS 像素之间的比例关系。高 DPR 屏幕可能需要更高分辨率图片，但应综合考虑图片实际显示尺寸和网络成本。

## 六、容器查询 Container Queries ⭐⭐⭐

媒体查询看视口，容器查询看组件所在容器。它更适合可复用组件：同一个卡片在窄侧栏和宽主内容区中采用不同布局。

```css
.card-list {
  container-type: inline-size;
}

.card {
  display: grid;
  gap: 12px;
}

@container (min-width: 520px) {
  .card {
    grid-template-columns: 160px minmax(0, 1fr);
    align-items: center;
  }
}
```

**注意：** 要让容器查询生效，需要在祖先容器上建立对应的 containment context；查询条件基于该容器，而不是当前组件的视口宽度。

## 七、响应式布局实战建议

- 页面主体：窄屏单列，宽屏侧栏 + 主内容。
- 卡片列表：`repeat(auto-fit, minmax(...))`。
- 表格：窄屏允许横向滚动，或转为卡片展示，不要强行压缩所有列。
- 导航：宽屏完整展示，窄屏使用菜单按钮并确保键盘可访问。
- 图片：设置 `max-width: 100%; height: auto;`，避免溢出。
