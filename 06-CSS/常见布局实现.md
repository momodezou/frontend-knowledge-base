# CSS 常见布局实现

> 本文以实战代码为主，覆盖前端开发和面试中常见的居中、两栏、三栏、圣杯、双飞翼、固定底部、等宽卡片和瀑布流布局。示例优先使用现代 Flex / Grid，经典布局用于理解原理。

## 一、水平垂直居中 ⭐⭐⭐

### 1. Flex

```css
.parent {
  display: flex;
  justify-content: center;
  align-items: center;
}
```

### 2. Grid

```css
.parent {
  display: grid;
  place-items: center;
}
```

### 3. 绝对定位 + transform

```css
.parent {
  position: relative;
}

.child {
  position: absolute;
  left: 50%;
  top: 50%;
  transform: translate(-50%, -50%);
}
```

**选择建议：** 现代普通布局优先 Flex / Grid；需要脱离文档流的弹层或覆盖层可考虑绝对定位。

## 二、两栏布局：固定侧栏 + 自适应主内容 ⭐⭐⭐

```css
.layout {
  display: flex;
  min-height: 100vh;
  gap: 16px;
}

.sidebar {
  flex: 0 0 240px;
}

.main {
  flex: 1;
  min-width: 0;
}
```

`min-width: 0` 很关键：Flex 项目默认最小尺寸可能受内容影响，长文本或宽表格可能撑破主区域。

Grid 写法：

```css
.layout {
  display: grid;
  grid-template-columns: 240px minmax(0, 1fr);
  gap: 16px;
}
```

## 三、三栏布局：左右固定，中间自适应 ⭐⭐⭐

```css
.layout {
  display: grid;
  grid-template-columns: 200px minmax(0, 1fr) 240px;
  gap: 16px;
}
```

响应式处理：

```css
@media (max-width: 900px) {
  .layout {
    grid-template-columns: 180px minmax(0, 1fr);
  }

  .right {
    display: none;
  }
}

@media (max-width: 600px) {
  .layout {
    grid-template-columns: minmax(0, 1fr);
  }
}
```

## 四、圣杯布局与双飞翼布局 ⭐⭐

两者是经典的三栏布局方案：中间主体优先，左右侧栏固定宽度。它们通常使用浮动、负 margin、相对定位或额外包裹层实现。

现代项目更推荐 Grid：

```css
.holy-grail {
  display: grid;
  grid-template:
    "header header header" auto
    "left main right" minmax(0, 1fr)
    "footer footer footer" auto
    / 200px minmax(0, 1fr) 200px;
  min-height: 100vh;
  gap: 12px;
}

.header { grid-area: header; }
.left { grid-area: left; }
.main { grid-area: main; min-width: 0; }
.right { grid-area: right; }
.footer { grid-area: footer; }

@media (max-width: 800px) {
  .holy-grail {
    grid-template:
      "header" auto
      "main" minmax(0, 1fr)
      "left" auto
      "right" auto
      "footer" auto
      / minmax(0, 1fr);
  }
}
```

**面试表达：** 圣杯和双飞翼的核心是中间内容优先、左右列占据固定空间；历史实现的区别主要在中间列的包裹结构和左右侧栏偏移方式。实际项目优先选择更易维护的 Grid / Flex。

## 五、固定底部布局（Footer 贴底） ⭐⭐⭐

页面内容不足一屏时，Footer 仍位于视口底部；内容超出时，Footer 正常被推到页面下方。

```css
.page {
  min-height: 100vh;
  display: flex;
  flex-direction: column;
}

.main {
  flex: 1;
}

.footer {
  flex: none;
}
```

也可以使用 Grid：

```css
.page {
  min-height: 100vh;
  display: grid;
  grid-template-rows: auto 1fr auto;
}
```

**易错点：** 使用 `position: fixed; bottom: 0` 会让 footer 脱离文档流，可能遮挡内容；这与“内容不足时贴底”的需求不同。

## 六、等高布局与等宽卡片 ⭐⭐

Flex：

```css
.cards {
  display: flex;
  gap: 16px;
  align-items: stretch;
}

.card {
  flex: 1;
  min-width: 0;
}
```

Grid：

```css
.cards {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
  gap: 16px;
}
```

响应式卡片：

```css
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  gap: 16px;
}
```

## 七、单行与多行文本省略 ⭐⭐⭐

### 单行省略

```css
.ellipsis {
  overflow: hidden;
  white-space: nowrap;
  text-overflow: ellipsis;
}
```

三个条件通常需要配合使用；元素还需要有可收缩或受限的宽度。

### 多行省略

```css
.ellipsis-multi {
  display: -webkit-box;
  -webkit-box-orient: vertical;
  -webkit-line-clamp: 3;
  overflow: hidden;
}
```

多行省略的兼容和标准化能力应结合目标浏览器验证。不要把 `text-overflow: ellipsis` 单独设置就认为多行文本一定会自动省略。

## 八、瀑布流布局 ⭐⭐

### CSS 多列方案

```css
.waterfall {
  columns: 3 240px;
  column-gap: 16px;
}

.waterfall-item {
  break-inside: avoid;
  margin-bottom: 16px;
}
```

优点是实现简单；缺点是内容通常按列流动，视觉顺序可能与期望的逐行顺序不同。

### Grid 方案

Grid 更适合规则二维网格；若要实现严格的动态高度瀑布流，可能需要 JavaScript 测量、CSS 多列或专门布局方案。不要把 `grid-auto-flow: dense` 等同于真正的 Masonry，它主要是网格自动放置填空行为，且可能改变视觉顺序。

## 九、布局排查清单

遇到页面布局异常时，按顺序检查：

1. 元素是否处于正常文档流？是否被 absolute / fixed 脱离？
2. 父容器使用的是 block、Flex 还是 Grid？
3. 宽高百分比是否有明确的包含块尺寸？
4. `box-sizing` 是否导致尺寸计算不一致？
5. Flex / Grid 项目是否被默认最小尺寸限制？是否需要 `min-width: 0`？
6. `overflow` 是否裁剪内容或改变滚动容器？
7. `position: sticky` 的祖先滚动容器是否符合预期？
8. 是否存在 margin 折叠或层叠上下文问题？
9. 是否需要在窄屏下改变布局，而不是继续压缩？
