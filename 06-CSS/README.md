
# CSS 知识体系

## 一、分类介绍

本目录用于系统整理 CSS 核心知识，包括基础语法、布局机制、视觉效果、动画、响应式设计及性能优化。

学习目标：

- 熟练掌握 CSS 常用属性和布局方案
- 理解盒模型、BFC、层叠上下文等核心机制
- 熟练使用 Flex 和 Grid 完成复杂布局
- 理解 CSS 动画与浏览器渲染之间的关系
- 能够解决常见布局问题和浏览器兼容问题
- 掌握 CSS 工程化及性能优化方法
