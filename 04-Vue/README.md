
# Vue 知识体系

## 一、分类介绍

本目录用于系统整理 Vue 框架相关知识，重点关注 Vue2、Vue3、核心 API、响应式原理、组件机制、状态管理及工程实践。

学习目标：

- 熟练使用 Vue2 和 Vue3 开发项目
- 深入理解 Vue3 响应式原理
- 理解 Vue 组件的创建、更新与销毁机制
- 掌握 Vue Router 和 Pinia
- 理解虚拟 DOM、Diff 算法及渲染机制
- 能够进行 Vue 项目性能优化和架构设计
