# JavaScript 原型、继承与 new

> **定位：** 从对象属性查找出发，理解 `prototype`、`[[Prototype]]`、`instanceof`、构造函数与 `class`。
>
> **面试优先级：** ⭐⭐⭐｜**前置知识：** [this 指向](./this.md)

## 一、必须区分的几个概念

| 名称 | 属于谁 | 作用 |
| --- | --- | --- |
| `[[Prototype]]` | 对象的内部属性 | 指向该对象的原型对象（或 `null`） |
| `Object.getPrototypeOf(obj)` | 获取对象原型的标准 API | 比直接访问历史遗留的 `__proto__` 更推荐 |
| `Fn.prototype` | 通常属于可构造的普通函数 | `new Fn()` 创建实例时用作实例的原型 |
| `constructor` | 普通属性（通常在原型上） | 通常指回构造函数，但**不是可靠类型证据** |

**核心关系：** `new Fn()` 构造实例后，通常有 `Object.getPrototypeOf(instance) === Fn.prototype`。但是 `Fn.prototype` 本身也是对象，也可以有它的原型。

```js
function Person(name) {
  this.name = name;
}
Person.prototype.say = function () {
  return `Hi, ${this.name}`;
};

const p = new Person('Ada');
console.log(Object.getPrototypeOf(p) === Person.prototype); // true
console.log(p.say()); // 'Hi, Ada'
```

## 二、原型链：如何查找属性 ⭐⭐⭐

读取 `obj.key` 时，若对象自身没有该属性，就顺着原型链向上查找，直到找到或走到 `null`；这就是 JavaScript 基于原型的继承基础。

```js
const base = { role: 'viewer' };
const user = Object.create(base);
user.name = 'Ada';

console.log(user.name); // 'Ada'：自身属性
console.log(user.role); // 'viewer'：原型链查找
console.log(Object.hasOwn(user, 'role')); // false
console.log('role' in user);              // true
```

- `Object.hasOwn(obj, key)`：只看对象自身是否有属性。
- `key in obj`：检查自身**以及原型链**。
- `for...in`：遍历可枚举字符串键，包含原型链上的可枚举属性；业务上通常配合 `Object.hasOwn()` 过滤。

**典型易错：** 创建 `Object.create(null)` 的对象没有 `Object.prototype` 上的方法，不能直接调用 `obj.toString()` 或 `obj.hasOwnProperty()`。

## 三、构造函数与 `new` 做了什么 ⭐⭐⭐

对常见的、可构造的普通函数，`new` 的教学模型可以概括为：

1. 创建新对象，将其原型设为构造函数的 `prototype`（如果该属性不为对象，按语言规则回退）。
2. 以新对象作为 `this` 执行构造函数。
3. 如果构造函数显式返回**对象**（包括函数），则使用该返回值；否则返回新对象。

```js
function User(name) {
  this.name = name;
  return 123; // 原始值不会取代 new 创建的实例
}
const u = new User('Tom');
console.log(u.name); // 'Tom'
```

箭头函数不可构造，没有可用于 `new` 的构造行为。手写简化版 `new` 可参考 [手写题](./手写题.md)。

## 四、`instanceof` 的含义与边界

普通情况下，`obj instanceof Fn` 检查 `Fn.prototype` 是否出现在 `obj` 的原型链上。

```js
function Animal() {}
const cat = new Animal();
console.log(cat instanceof Animal); // true
console.log(cat instanceof Object); // true

const another = Object.create(Animal.prototype);
console.log(another instanceof Animal); // true：不要求真正执行过构造函数
```

**特别注意：** `instanceof` 可以通过构造函数的 `Symbol.hasInstance` 自定义；其结果不一定等价于手动遍历原型链。跨不同 iframe / realm 的内建构造函数也可能让 `instanceof Array` 产生误判，判断数组请用 `Array.isArray()`。

## 五、继承方式：从手工原型链到 class ⭐⭐⭐

### 1. 组合式继承的思路

早期写法通常在子构造函数中调用父构造函数，以初始化实例状态，同时设置子类原型链共享方法。现代代码优先使用 `class extends` 表达同一意图。

```js
function Animal(name) {
  this.name = name;
}
Animal.prototype.speak = function () { return this.name; };

function Dog(name) {
  Animal.call(this, name); // 初始化当前实例
}
Dog.prototype = Object.create(Animal.prototype);
Dog.prototype.constructor = Dog;

const dog = new Dog('Lucky');
console.log(dog.speak()); // 'Lucky'
console.log(dog instanceof Animal); // true
```

### 2. `class` 不是另一个完全独立的继承系统

```js
class AnimalClass {
  constructor(name) { this.name = name; }
  speak() { return `I'm ${this.name}`; }
}

class DogClass extends AnimalClass {
  constructor(name, breed) {
    super(name); // 派生类构造函数中使用 this 前必须完成父类初始化
    this.breed = breed;
  }
  speak() { return `${super.speak()} (${this.breed})`; }
}

const d = new DogClass('Lucky', 'Shiba');
console.log(d.speak()); // "I'm Lucky (Shiba)"
console.log(d instanceof AnimalClass); // true
```

`class` 基于原型机制，还增加了更严格的语义：类构造函数不能脱离 `new` 直接调用；类体始终处于严格模式；方法默认不可枚举。

## 六、经典易错与真实项目场景

### 错误 1：把属性放到原型上造成共享状态

```js
function Cart() {}
Cart.prototype.items = []; // ❌ 所有实例共享同一数组

const a = new Cart();
const b = new Cart();
a.items.push('book');
console.log(b.items); // ['book']

class SafeCart {
  constructor() { this.items = []; } // ✅ 实例独立状态
}
```

### 错误 2：盲目依赖 `constructor` 判断类型

```js
function A() {}
function B() {}
B.prototype = Object.create(A.prototype); // 未手工恢复 constructor
const b = new B();
console.log(b.constructor === B); // false：默认沿原型链查到 A
```

### 错误 3：原型污染

当外部输入能够控制对象的原型相关属性时，可能造成原型污染。合并不可信对象时，应严格校验键、使用安全的合并策略，必要时使用 `Object.create(null)`、`Map` 等数据结构。不要直接把用户输入的对象深度合并到全局默认配置中。

## 七、高频面试问答

1. `prototype` 和 `__proto__` 有何区别？（前者是函数的普通属性，后者是访问内部原型的历史访问器；推荐 `Object.getPrototypeOf`。）
2. 为什么 `Object.create(Animal.prototype) instanceof Animal` 为 `true`？
3. `new` 做了哪几步？返回对象时有什么特殊规则？
4. 原型链如何影响 `in`、`Object.hasOwn()`、`for...in`？
5. `class` 是否改变了 JS 的原型继承本质？
6. 为什么把数组放在构造函数原型上会导致实例间共享？
