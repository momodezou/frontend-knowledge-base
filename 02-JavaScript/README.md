
# JavaScript 知识体系

## 一、分类介绍

本目录用于系统学习和整理 JavaScript 核心知识，重点关注语言基础、执行机制、异步编程、面向对象及高级特性。

学习目标：
- 熟练掌握 JavaScript 核心语法
- 理解作用域、闭包、原型链等底层机制
- 理解 JavaScript 异步执行机制
- 能够独立编写常见手写题
- 能够结合实际项目应用相关知识
