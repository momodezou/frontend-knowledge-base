# Algorithms & Data Structures

## 一、分类介绍

本目录用于记录和整理算法与数据结构相关知识，包括基础概念、经典算法、LeetCode 练习题、解题思路及代码实现。

学习目标：

- 掌握常见数据结构及其应用场景
- 理解常见算法的核心思想
- 熟练使用 JavaScript 实现算法
- 掌握时间复杂度和空间复杂度分析
- 提高算法问题分析和独立解决能力

## 二、知识分类

| 分类 | 主要内容 |
|---|---|
| 数组 | 数组操作、双指针、滑动窗口 |
| 字符串 | 字符串处理、匹配、回文 |
| 链表 | 单链表、双向链表、链表反转 |
| 栈与队列 | 栈、队列、单调栈、单调队列 |
| 哈希表 | HashMap、HashSet、哈希应用 |
| 二叉树 | 二叉树遍历、二叉搜索树 |
| 堆 | 大顶堆、小顶堆、优先队列 |
| 排序 | 冒泡、插入、归并、快速排序 |
| 二分查找 | 基础二分、边界查找 |
| 递归与回溯 | 全排列、组合、子集、剪枝 |
| 贪心算法 | 区间问题、局部最优策略 |
| 动态规划 | 背包问题、路径问题、状态转移 |
| 图算法 | DFS、BFS、拓扑排序、最短路径 |

## 三、算法题记录规范

每道算法题尽量包含：

1. 题目描述
2. 输入与输出
3. 解题思路
4. JavaScript 代码实现
5. 时间复杂度与空间复杂度
6. 易错点及优化思路
7. 掌握情况

新增算法题时，优先使用 `_templates/TEMPLATE-ALGORITHM.md` 模板。

## 四、学习建议

- 先理解数据结构，再学习对应算法。
- 优先独立思考，不直接复制答案。
- 同一道题尽量尝试多种解法。
- 完成后分析时间复杂度和空间复杂度。
- 定期重新练习历史题目，检验是否真正掌握。
