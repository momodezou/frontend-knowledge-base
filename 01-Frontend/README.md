# Frontend 基础知识体系

> **定位：** 本目录是个人前端技术知识库的基础入口，聚焦 HTML、DOM/BOM、页面开发流程、响应式、模块化、常用设计模式、安全意识和常见问题排查。它强调**能理解、能应用、能排错**，不是单纯的面试题汇总。

## 一、学习目标

- 理解网页由 HTML、CSS 和 JavaScript 如何协作构成。
- 能写出语义清晰、可访问的页面和表单。
- 掌握基本 DOM 操作、浏览器对象与事件处理。
- 能处理页面加载、空数据、错误、重试等常见业务状态。
- 能开发适配桌面和手机的响应式页面。
- 能使用 ES Modules 组织代码，理解常见设计模式的用途。
- 具备基本安全意识和系统化排查问题的能力。

## 二、知识地图

| 方向 | 必须理解的核心问题 | 学习重点 |
| --- | --- | --- |
| HTML 与表单 | 标签为什么要有语义？表单怎样正确提交？ | `main`、`article`、`label`、`name`、原生校验、a11y |
| DOM 与 BOM | JavaScript 如何操作页面和浏览器？ | DOM 树、节点查询与修改、事件委托、location/history |
| 页面开发 | 一个页面怎样从设计稿走向可用产品？ | Loading/Empty/Error、API、CSR/SSR/SSG |
| 响应式 | 为什么同一页面在手机和电脑上布局不同？ | viewport、断点、单位、图片适配、容器查询 |
| 模块化 | 代码怎样拆开，又能协作？ | import/export、动态导入、CommonJS、依赖关系 |
| 设计模式 | 遇到重复问题，如何复用成熟思路？ | 工厂、单例、发布订阅、策略、适配器 |
| 安全基础 | 哪些数据不可信？权限应该在哪里判断？ | XSS、CSRF、Cookie、认证/授权、密钥保护 |
| 问题排查 | 白屏、404、跨域、样式异常时怎么定位？ | Console、Network、Elements、Performance |

## 四、推荐学习顺序

1. **HTML语义化与表单** → 先把网页结构和表单基础打好。
2. **DOM与BOM** → 理解 JavaScript 怎样操作页面和浏览器。
3. **前端页面开发基础** → 做一个带加载、空状态和错误处理的小页面。
4. **响应式与移动端适配** → 让页面在手机和平板上也能使用。
5. **前端模块化基础** → 学会把功能拆分为可维护模块。
6. **前端安全基础** → 建立输入、身份和权限的安全意识。
7. **Web开发常见问题** → 用开发者工具练习独立排查。
8. **前端常见设计模式** → 在拥有实际业务场景后再理解模式取舍。

不要求一次性全部学完。建议每看完一篇，就完成其中一至两个代码实践或自测问题。

## 五、与其他目录的边界

为了避免长期知识库重复堆积：

- JavaScript 的语言机制与手写题 → `02-JavaScript/`。
- TypeScript 类型系统 → `03-TypeScript/`。
- Vue/React 框架深度内容 → `04-Vue/`、`05-React/`。
- 盒模型、Flex、Grid 和 CSS 性能细节 → `06-CSS/`。
- HTTP/TLS、DNS、浏览器渲染、跨域与 Web 安全原理 → `07-Browser-Network/`。
- 构建工具、CI/CD 与大型工程配置 → `10-Engineering/`。
- 真实业务模块、技术选型和项目复盘 → `12-Project-Practice/`。

本目录只保留**入门框架、通用知识和可操作的基础实践**，深度专题移至对应分类。

## 六、知识文档维护规则

- 新增知识优先补充到最接近的现有专题，避免一题一个文件。
- 每个知识点优先回答三个问题：**是什么、为什么、什么时候用**。
- 重要原理配通俗解释和最小可运行代码示例。
- 易错点要说明“错在哪里、如何验证、怎么改”。
- 每篇文档保留高频面试自测题和参考资料。
- 技术结论随标准与浏览器实现更新，发现错误及时修正。
