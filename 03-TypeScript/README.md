
# TypeScript 知识体系

## 一、分类介绍

本目录用于系统学习 TypeScript，重点掌握类型系统、类型推导、泛型及高级类型。

学习目标：
- 熟练掌握 TypeScript 基础语法
- 理解 TypeScript 类型系统
- 能够独立设计复杂类型
- 熟练使用 TypeScript 开发 Vue 和 React 项目
